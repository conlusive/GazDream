# Запуск сайту на сервері

Підходить будь-який VPS із Docker (Ubuntu, Debian тощо). Потрібен **постійний диск**: на ньому зберігаються ціни палива з адмінки та резервний журнал заявок.

## 1. Підготовка

1. Встановити Docker і Docker Compose.
2. Скопіювати проєкт на сервер (`git clone https://github.com/conlusive/GazDream.git`, потрібна папка `web/`).
3. У папці `web/` створити файл `.env` (не комітити!) за зразком `.env.example`:

| Змінна | Призначення |
|---|---|
| `SITE_URL` | публічна адреса сайту, напр. `https://eco-strassmayr.example` (потрібна **під час збірки**) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | доступ до пошти для відправки листів |
| `LEADS_EMAIL_TO` | скринька, куди приходять заявки (імовірно `sales@strasslider.com`) |
| `LEADS_EMAIL_FROM` | відправник (за замовчуванням `SMTP_USER`) |
| `ADMIN_PASSWORD` | пароль адмінки цін `/admin` |
| `ADMIN_SESSION_SECRET` | випадковий рядок від 32 символів |

Згенерувати секрет: `openssl rand -hex 32`.

## 2. Запуск

```bash
cd web
docker compose up -d --build
```

Сайт слухає порт `3000`. Дані (`prices.json`, `leads.jsonl`) лежать у томі `gazdream-data` і переживають перезапуск та оновлення.

Оновлення: `git pull && docker compose up -d --build`.

## 3. HTTPS і домен

Перед контейнером потрібен зворотний проксі з сертифікатом. Найпростіше: **Caddy**.

```
eco-strassmayr.example {
    reverse_proxy 127.0.0.1:3000
}
```

Caddy сам отримає й оновлюватиме сертифікат. Заголовок `X-Forwarded-For` передається автоматично, він потрібен для лімітів на заявки та вхід в адмінку.

## 4. Після першого запуску

- [ ] Відкрити `https://домен/pl`, перевірити, що сторінка завантажилась.
- [ ] Надіслати тестову заявку з «Kontakt» і швидкої форми: лист має прийти на `LEADS_EMAIL_TO`.
- [ ] У калькуляторі надіслати результат собі на пошту.
- [ ] Увійти на `/admin`, ввести актуальні ціни газу, щепи й пелети (EUR і PLN).
- [ ] Перевірити `https://домен/sitemap.xml` та `https://домен/robots.txt` (мають містити ваш домен).
- [ ] Додати сайт у Google Search Console й подати `sitemap.xml`.

## 5. Резервні копії

Зберігати том `gazdream-data` (там ціни й журнал заявок). Приклад копії в архів:

```bash
docker run --rm -v gazdream-data:/data -v "$PWD":/backup alpine tar czf /backup/gazdream-data-$(date +%F).tgz -C /data .
```

Журнал заявок містить персональні дані: тримати його приватним і не публікувати.

## 6. Перевірки перед релізом (локально)

```bash
npm run build      # продакшен-збірка
npm test           # юніт-тести логіки (калькулятор, доставка листів)
npm run e2e        # браузерні тести (потрібен Google Chrome)
```

## 7. Обмеження

- Ліміти спроб (заявки, звіт на пошту, вхід в адмінку) зберігаються в пам'яті одного екземпляра. Для одного контейнера цього достатньо; для кількох потрібне спільне сховище.
- Образ Docker у цій сесії не збирався (на машині розробника не запущений Docker-демон). Перевірена автономна збірка Next, яку використовує образ: вона працює, але перша збірка образу на сервері може виявити дрібниці.
