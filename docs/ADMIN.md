# Адмін-панель: підключення й користування

Адреса: `https://ваш-сайт/admin` (мова панелі українська, у пошуковики вона не потрапляє).

## 1. Підключення бази даних (один раз)

Заявки, ціни, користувачі й відгуки зберігаються в базі **Postgres**. На Vercel (і будь-якому хостингу без постійного диска) база обов'язкова, на VPS рекомендована.

**Варіант А: Supabase (безкоштовно)**
1. supabase.com → New project (регіон ближче до Польщі, наприклад Frankfurt). Запам'ятайте пароль бази.
2. Project Settings → Database → **Connection string** → вкладка **Transaction pooler** (порт 6543). Скопіюйте рядок і підставте свій пароль.
3. У Vercel: Project → Settings → Environment Variables → додати `DATABASE_URL` = цей рядок (Production). Тоді Deployments → ⋯ → **Redeploy**.

**Варіант Б: Neon (безкоштовно)**: neon.tech → новий проєкт → Connection string (з `-pooler` у назві хосту) → так само у `DATABASE_URL`.

Таблиці створюються самі при першому запуску (міграції). Усі вони закриті від публічного доступу (RLS, без прав для `anon`/`authenticated`).

## 2. Перший вхід

1. Задайте змінні `ADMIN_EMAIL` (за замовчуванням `admin`) і `ADMIN_PASSWORD`, зробіть Redeploy.
2. Відкрийте `/admin` і увійдіть цими даними: буде створено першого адміністратора.
3. Одразу змініть пароль: «Мій обліковий запис». Після цього змінну `ADMIN_PASSWORD` можна видалити, вона більше не використовується.
4. У розділі «Користувачі» додайте менеджерів.

## 3. Що є в панелі

| Розділ | Хто бачить | Що робить |
|---|---|---|
| Огляд | всі | нові заявки, динаміка за 14 днів, джерела, мови |
| Заявки | всі | список із пошуком і фільтрами, картка заявки, статуси («Нова», «В роботі», «Закрита», «Спам»), нотатки, експорт у CSV |
| Ціни палива | адмін | ціни газу, щепи, пелети (EUR і PLN), історія змін; калькулятор оновлюється одразу |
| Калькулятор | адмін | витрата палива по культурах (кукурудза, соя, ріпак), вологість за замовчуванням, ПДВ по країнах |
| Контакти й відгуки | адмін | телефони й пошта на сайті; відгуки клієнтів (показ по мовах, порядок) |
| Користувачі | адмін | створення, ролі, вимкнення доступу, скидання пароля |
| Журнал дій | адмін | хто й що змінював |
| Мій обліковий запис | всі | зміна власного пароля |

**Ролі.** Адміністратор бачить усе. Менеджер бачить лише заявки: може змінювати статус і додавати нотатки, але не видаляти заявки й не змінювати налаштування.

## 4. Безпека

- Паролі зберігаються як хеші (scrypt), сесії у базі, cookie `HttpOnly` + `SameSite=Strict`, термін сесії 7 днів.
- 5 невдалих спроб входу за 15 хвилин блокують спроби з цієї адреси та для цього e-mail.
- Зміна пароля виводить користувача з усіх пристроїв; вимкнення користувача негайно закриває доступ.
- Не можна вимкнути чи понизити останнього адміністратора.
- CSV-експорт нейтралізує формули (`=`, `+`, `-`, `@`), щоб файл безпечно відкривався в Excel.
- Усі зміни налаштувань і дії над заявками потрапляють у журнал.

## 5. Заявки й пошта

Кожна заявка (форма «Контакти», швидкий запит, звіт калькулятора) **спершу** зберігається в базі, а також надсилається листом на `LEADS_EMAIL_TO`. Якщо пошта не налаштована або тимчасово не працює, заявка все одно з'являється в адмінці (у картці написано, що лист не надіслано). Якщо недоступна й база, заявка йде листом і записується в аварійний файл.

## 6. Резервні копії

- Supabase/Neon роблять автоматичні копії (перевірте строк зберігання у вашому тарифі).
- Для ручної копії: `pg_dump "$DATABASE_URL" > backup.sql`.
- Експорт заявок у CSV доступний у будь-який час у розділі «Заявки».
